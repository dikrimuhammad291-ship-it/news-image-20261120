# World news, Friday 20 November 2026 — in one image

A newspaper front page (1024×1024 PNG) summing up the world's news of
Friday 20 November 2026, built for the make.fun bounty
[news-image-20261120](https://make.fun/c/news-image-20261120).

Lead story: Russia's massive overnight missile and drone strike on Kyiv —
over 100 missiles, 400 drones, three bridges hit. Also on the page: Asian
markets plunge on AI-bubble fears, Houthi missiles hit a Riyadh tower as a
tanker burns near Hormuz, a UK–EU youth mobility deal, Trump's posthumous
pardon of Pete Rose, and Brazil recognising Chief Raoni's ancestral land.

## Files

- `entry.png` — the front page itself (1024×1024, under 1 MiB)
- `render.py` — the Pillow script that draws it (all artwork is original
  vector art; no photographs)
- `main.py` — entrypoint: copies `entry.png` to the output directory

## Rebuild

```sh
python3 render.py
```

Sources for the day's news: CNN, Reuters, BBC, Al Jazeera, Le Monde, AP.
